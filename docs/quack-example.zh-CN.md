# QUACK!!! on ICE：3D 示例

[English](quack-example.md) | **简体中文** · [README](../README.zh-CN.md) · [用户指南](designer-guide.zh-CN.md)

让三只鸭子滑向面包，并利用吃饱的鸭子挡停其他鸭子。打开 [examples/quack.tscn](../examples/quack.tscn)，选择 **Run Current Scene**，或在 Grid Levels 中打开 [examples/levels/quack.tres](../examples/levels/quack.tres)，点击 **Playtest**。编辑操作见[用户指南](designer-guide.zh-CN.md)。

点击鸭子即可选中，其立方体背景变黑，其他鸭子保持白底。WASD／方向键始终对应 −Z／+Z／−X／+X，不受摄像机旋转影响；棋盘周围的标记显示方向。中键拖动环绕，Shift+中键拖动平移，滚轮缩放，F 完整取景。Z／Y／R 分别撤销、重做和重开。选择不记入动作历史；动画期间的点击会被忽略，避免缓冲移动意外切换角色。

饥饿的鸭子会一直滑行，直到被挡住或吃掉一块面包。鸭子互相阻挡，不能推动。吃面包会立即结束滑行；吃饱的鸭子仍可滑行，但不能穿过或再吃面包。失去支撑的鸭子会下落，落地后继续沿原方向滑行。每次网格位移后都会检查面包交互：下落时吃到面包会继续完成下落，但停止水平滑行；面包也能支撑吃饱的鸭子而不被吃掉。鸭子掉出边界即失败，吃完三块面包即获胜。一次撤销恢复整次滑行，包括全部下落、进食、面包移除和胜负结果。重开本身也可撤销。

## 已验证解法

此解法适用于随附且未编辑的示例关卡，由 [tests/test_quack.gd](../tests/test_quack.gd) 检查。坐标为 `(X, Y, Z)`，Y 表示高度。A 在上层平台 `(-1, 2, 1)`，B 在 `(0, 0, 3)`，C 在 `(0, 0, 0)`。每次切换角色前，先点击表中对应的鸭子。

| 步骤 | 鸭子 | 按键 | 终点 | 结果 |
| --- | --- | --- | --- | --- |
| 1 | A | D | `(3, 0, 1)` | 在 `(0, 0, 1)` 落地，继续滑行并吃掉面包 A。 |
| 2 | A | A | `(0, 0, 1)` | 吃饱的 A 滑回西侧墙边。 |
| 3 | B | D | `(2, 0, 3)` | B 吃掉面包 B。 |
| 4 | C | D | `(3, 0, 0)` | C 滑到东侧墙边。 |
| 5 | A | W | `(0, 0, 0)` | 吃饱的 A 再次移动，成为 C 的挡停物。 |
| 6 | C | A | `(1, 0, 0)` | C 被 A 挡停，对齐狭窄的面包通道。 |
| 7 | C | S | `(1, 0, 2)` | C 吃掉最后一块面包，全部鸭子吃饱。 |

第 5、6 步利用吃饱的 A 将 C 挡停在最后一块面包的通道前。吃饱的鸭子仍可移动。
