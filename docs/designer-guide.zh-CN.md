## 新建、保存与试玩

打开 Godot 顶部的 **Grid Levels**。点击 **File → New level** 创建带默认实体面板的关卡，或 **File → Open…** 打开 `.tres`。选择实体、绘制、**Save** 保存或 **File → Save as…** 另存，随后点击 **Playtest**；**Stop** 返回编辑。

试玩使用包含未保存编辑的临时副本。移动、下落和游戏历史不会写回设计好的关卡；关闭 Godot 前仍需保存编辑。标题中的 `*` 表示有未保存更改；新建或打开其他关卡前会询问是否放弃。工作区会记住上次保存的关卡。

左栏集中展示实体定义；顶栏直接显示 **Paint / Erase / Select** 三种工具，并标记当前工具，画笔旋转和镜像只在绘制时显示。右栏分为 **Selected entity**（选中实体）和 **Level**（关卡）两个页签；左右栏均可滚动并调整宽度。视口下方显示当前操作提示，**Help** 查看完整快捷键。底部操作反馈与实时坐标分开，鼠标移动不会覆盖反馈；**Details** 查看完整结果。没有运行场景时，Stop 不可用。

## 绘制与搭建

**Y 是高度，XZ 是水平面**，占用格均使用整数坐标。常见布局是地面位于 `Y=-1`、玩家和目标位于 `Y=0`。

| 工具 | 用途 |
| --- | --- |
| **Paint (1)** 绘制 | 点击或拖动放置所选定义；预览包含完整形状、旋转和镜像。 |
| **Erase (2)** 擦除 | 点击或拖动模型，删除整个实体及其全部占用格。 |
| **Select (3)** 选择 | 点击实体查看或移动；普通点击空白清空选择。 |
| 右键点击 | 拾取实体的定义、旋转和镜像作为画笔。 |
| **Quarter turns / Mirror brush** | 绕 Y 轴以 90° 旋转／沿局部 X 镜像。 |

绘制会吸附到所有实体占格的表面，包括高处顶面和侧面；面包等非实心实体也可作为绘制表面进行堆叠。空白处使用 **Height** 高度平面。实心实体若重叠，会整体向上寻找空位；目标等非实心实体可共用格子。每笔以落笔时的表面为准，每个目标只绘制一次，避免轻微移动意外叠高；需要叠一层时松开重新绘制。整笔可一次撤销。

在 **Level → Fill ground** 中填地：选择带 `ground=true` 的单格定义，设置 **Height**、**Width**、**Depth**，点击 **Fill ground**。这里的 Height 与顶栏放置平面保持同步。矩形从 `X=0, Z=0` 开始，跳过已有实心格；一次填充可整体撤销。

**Level → Transform entire level** 中的 **Rotate level 90°** 和 **Mirror level on X** 会同时变换全部实体的位置和朝向，支持保存与撤销。

## 选择与移动

**Shift+点击**增减选择；Shift 点击空白保持选择；普通点击实体只选中它。手柄位于最后选中的实体上。

- 拖动 **XYZ 箭头**沿世界单轴移动，或拖动 **XY/XZ/YZ 方形手柄**在平面内移动。X 红、Y 绿、Z 蓝；接近侧对视线的手柄会隐藏，可环绕视角后操作。
- 按整格吸附；多选时保持相对位置、形状、朝向和属性覆盖。只检查终点，拖动路径可经过障碍。
- 合法位置松开立即提交，一次撤销即可恢复。非法位置常亮红色，松开后整组恢复原位；**Esc**、隐藏工作区或窗口失焦会取消未完成移动。未移动不产生历史。
- **Duplicate** 将整组向右复制一格，必要时一起向上寻找空位，成功后选中新副本，失败不创建副本。**Delete** 或在 Select 模式按 **Delete** 删除整组。每次操作可整体撤销。

选择本身不记录历史；撤销删除会恢复实体，但不会重新选中。打开其他关卡或进入形状编辑会清空选择。多选时禁用单实体坐标、朝向、覆盖属性和 End 贴地。

### End 向下贴地

Select 下**只选一个实体**，按 **End** 沿 Y 向下贴到最近的实心支撑，保持 X/Z 不变。地面、墙顶和箱子均可支撑，非实心标记不能。旋转／镜像后的完整形状整体下移，任一占格得到支撑即停下；关卡重力关闭时也可使用。

拖动时保持左键按下再按 End，贴地后可继续使用原手柄移动；即使用 X/Z 手柄，贴地也会改变 Y。松开将拖动和贴地合并提交，Esc 整体取消。不拖动时按 End 会立即提交，无需点击 **Apply entity changes**。

没有支撑、起点非法或已经贴地时不改变位置和历史。失败原因显示在底部状态行，悬停可查看完整内容。

### 高亮与拾取

选中模型表面以蓝色呼吸高亮并保留纹理。Erase 保留选择、隐藏蓝色，并让鼠标指向的实体以红色呼吸；非法移动使用常亮红色。高亮遵循遮挡关系。

Select／Erase 命中最近可见模型表面，包括占格外的模型部分，并可穿过空洞及受支持材质的透明像素。QUACK 白底仍不透明、可拾取；编辑器用蓝色反馈，游戏中选鸭才会变黑底。Paint 使用逻辑占格表面；外观不改变游戏占格。自定义 Shader 的支持范围见 [模型表面支持说明](editor-surface-coverage.md)。

## 实体定义、属性覆盖与形状

左侧面板展示可复用的**实体定义**，多个实体可共享同一定义。**+ Entity** 新建，**Import…** 导入，**Edit in Inspector** 修改默认值，**Definition options → Save definition as…** 保存为可复用 `.tres`。定义也可内嵌在关卡中；保存关卡时还会保存外部引用的定义和规则配置。

定义包含占格、实心／可移动／受重力影响、颜色、可选 **Visual Scene** 和玩法属性。修改默认值会影响所有继承该值的实体。

只修改某一个实体：

1. 选中它，在右栏 **Selected entity** 页签修改 X/Y/Z、**Quarter turns** 或 **Mirrored**。
2. 展开 **Property overrides**，只添加需要替换的键，并选合适类型，例如浮点数 `weight=4.0`。
3. 点击 **Apply entity changes**。非法位置会被拒绝。

移除某个覆盖键即可恢复继承。**Reset all overrides** 仅清空草稿，点击 Apply 才生效。复制实体会保留其覆盖值和朝向。

| 属性 | 含义 |
| --- | --- |
| `solid`、`movable`、`gravity` | 核心占格、移动、重力行为，可覆盖定义中的对应开关。 |
| `player` | 允许在游戏中选为操作角色。 |
| `can_push`、`pushable` | 默认推动规则下，角色能推动／目标可被推动。 |
| `transmits_push` | 被推动时能否继续推动前方实体；普通和 L 形箱子默认允许连推。 |
| `strength`、`weight` | 使用 `GGStrengthPushRule` 时，角色力量需覆盖全部被推实体的总重量。 |

其他属性由玩法规则解释。连推按实体配置，没有全关卡连推开关。编程扩展见 [自定义推动](extending.md#custom-pushing)。

### 编辑占用格

选择定义，开启 **Edit occupied cells**。**1** 添加、**2** 删除，在 **Height** 所在层点击或拖动；**3** 无效。改变高度可编辑三维形状，最后一个占格不能删除。点击 **Return to level** 或关闭开关，返回关卡并恢复之前的关卡工具。横幅明确提示正在修改的共享定义；形状编辑时禁用 Select 和 Level 页签。

形状修改影响所有共享定义的实体，支持撤销；修改后点击 **Validate** 检查重叠。模型与形状独立：**Visual Scene** 使用 `Node3D` 场景，原点应与实体原点一致；网格模型和碰撞体不会自动生成占格。

## 摄像机与快捷键

先点击视口获取焦点。**WASD** 沿视角自由飞行，无需按鼠标；**Q/E** 沿世界 Y 下降／上升。在 Select 模式选中实体后，每次按下 **Q/E** 改为让全部选中实体降低／抬升一格，长按不重复移动。多选保持相对位置；目标位置无效时拒绝整组移动，每次成功移动可单独撤销。拖动结束后再使用此快捷键。选中实体时，按住右键配合 **Q/E** 仍可控制摄像机升降。右键拖动原地转向；右键+滚轮调整速度，默认 8 格/秒，范围 0.25–128。摄像机可穿过实体、进入棋盘下方。

飞行和 Shift+中键平移会让放置平面随摄像机上下移动，Height 按整格对齐；环绕和缩放保持 Height。**Page Up/Down** 单独升降放置平面一格；手动修改 Height 后，以新高度继续移动。

绘制或移动实体结束后再导航；导航时隐藏画笔预览。松开按键即停止飞行；Esc、弹窗、失焦或离开工作区会停止导航并释放光标。

| --- | --- | --- |

| 编辑 | 左键点击／拖动 | 使用当前工具 |
| Select | **Shift+点击** | 增减选择 |
| Select 单选／多选 | **Delete** | 删除选中实体 |
| Select 视口，单选／多选且未拖动 | **Q / E** | 每次按下降低／抬升选中实体一格 |
| Select | 拖动轴／平面手柄 | 按整格移动选中实体 |
| Select 单选 | **End**，静止或拖动中 | 向下贴到支撑面 |
| 移动中 | **Esc** | 取消整次移动 |
| 编辑 | 右键点击 | 拾取画笔配置 |
| 编辑视口 | **WASD**、**Q/E**（选中实体时右键+Q/E） | 沿视角飞行；沿 Y 下降／上升 |
| 编辑视口 | 右键拖动／右键+滚轮 | 转向／调整飞行速度 |
| 编辑工作区 | **Page Up / Page Down** | 放置平面升／降一格 |
| 导航中 | **Esc** | 停止并释放光标 |
| 形状编辑 | **1 / 2**，左键点击／拖动 | 添加／删除占格 |
| 编辑 | **Ctrl/Cmd+S** | 保存 |
| 编辑 | **Ctrl/Cmd+Z** | 撤销 |
| 编辑 | **Ctrl/Cmd+Shift+Z** 或 **Ctrl/Cmd+Y** | 重做 |
| 编辑或游玩 | 中键拖动／**Shift+中键拖动** | 环绕／平移 |
| 编辑或游玩 | 滚轮／**F** | 缩放／完整取景 |
| 游玩 | 空闲时点击玩家实体 | 切换角色 |
| 游玩 | **WASD／方向键** | 固定棋盘方向：W −Z、S +Z、A −X、D +X |

工具键、Delete 和 End 需要 Grid Levels 焦点、不按修饰键；文本、属性输入和弹窗保留正常行为。切换工具需先结束鼠标笔画／拖动，视口操作需视口焦点。独立示例可使用 Godot 的运行项目、运行当前场景和停止按钮，按键以编辑器配置为准。

编辑撤销覆盖笔画、实体属性、整组移动／复制／删除、形状、填地、关卡设置和整关变换。Godot Inspector 中的共享默认值使用 Godot 自带资源编辑与撤销流程。

## 规则、校验与游玩

在 **Level** 页签设置标题、**Enable gravity** 和 **Fall-out height** 后，点击 **Apply level settings**。可选 **Game rule** 资源，并在 Inspector 中配置其推动规则。

地面需要显式放置。开启重力时，任一占格下方有支撑即可托住整个刚性实体，悬挑不倾倒；失去支撑的堆叠实体一起下落。玩家掉出边界则失败，其他实体从本次尝试移除，均可撤销恢复。

| 规则 | 目标 |
| --- | --- |
| 推箱子 | 至少一个目标，且每个目标格都有箱子；可有多余箱子，多格箱子可覆盖多个目标。 |
| 管道 | 所有终点通过互相匹配的端口连到源头；连通管道亮起。 |
| QUACK | 喂饱全部三只鸭子；滑行、下落和吃面包组成一个动作。[完整规则与解法](quack-example.md)。 |
| 无规则 | 测试移动与重力，不提供内置胜利条件。 |

**Validate** 检查资源版本、定义与 ID 缺失／非法、形状为空／重复、实心重叠及起点处于掉落边界或以下。保存与试玩也会校验。

空闲时点击玩家实体可切换角色，前景占格可能挡住拾取。角色仍存在时，撤销／重做／重开保留选择。旋转摄像机不改变移动方向。快速按键最多缓冲四次移动并加速动画；长按重复不会积压队列。撤销／重做／重开清空缓冲，等待当前动作结束后执行。

**Z** 撤销完整动作，包括推动、下落、移除和机制状态；**Y** 重做；**R** 重开，重开本身也可撤销。成功或失败后仍能回退。战役和持久进度由接入项目实现，可连接运行时的 [完成／失败信号](extending.md#visuals-and-lifecycle)。
