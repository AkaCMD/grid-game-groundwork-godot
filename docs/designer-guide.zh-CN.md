# 用户指南

[English](designer-guide.md) | **简体中文** · [README](../README.zh-CN.md)

在 [Grid Levels](../addons/grid_game_groundwork/editor/panel.gd) 中编辑起始布局，再用独立试玩检查效果。自定义玩法见[扩展指南](extending.zh-CN.md)。

## 新建、保存与试玩

打开 Godot 顶部的 **Grid Levels**。若未显示，在 **项目 → 项目设置 → 插件**中启用 **Grid Game Groundwork**。

1. 选择 **File → New level**，或通过 **File → Open…** 打开已有 `.tres`。
2. 在左侧选择定义，在视口中绘制。
3. 点击 **Save**；新建文件或复制布局时，使用 **File → Save as…**。
4. 点击 **Playtest** 测试，**Stop** 返回编辑。

新关卡带默认实体列表，但没有地面或玩法规则。试玩包含未保存编辑，不会改变设计好的关卡。关闭 Godot 前需保存。`*` 表示未保存更改；新建／打开前会询问是否放弃。编辑器记住上次保存的关卡。

右栏编辑 **Selected entity**（选中实体）和 **Level**（关卡）设置。**Help** 查看快捷键，**Details** 查看上次操作的完整结果。

## 绘制与搭建

**Y 是高度，XZ 是水平面**，占格使用整数坐标。常见布局为地面 `Y=-1`，玩家和目标 `Y=0`。

| 工具 | 用途 |
| --- | --- |
| **Paint (1)** 绘制 | 点击／拖动放置所选定义，预览显示完整形状。 |
| **Erase (2)** 擦除 | 点击／拖动模型，删除整个实体。 |
| **Select (3)** 选择 | 点击实体查看或移动，点击空白清空选择。 |
| 右键点击 | 拾取实体的定义、旋转和镜像作为画笔。 |
| **Quarter turns / Mirror brush** | 绕 Y 轴以 90° 旋转／沿局部 X 镜像。 |

Paint 吸附到占格顶面和侧面，包括非实心实体；空白处使用 **Height**。实心重叠时自动抬升，直到完整形状放得下；非实心实体可共用格子。每笔保持落笔时的表面，每个目标只绘制一次，整笔可一次撤销。需要再叠一层时，重新落笔。

**Q/E** 每按一次沿世界 Y 调整预览一格，从当前显示位置开始，包含自动抬升高度。先松开鼠标，长按不连发。偏移跟随指向表面，空白处相对于 Height。实心重叠或占格位于 **Fall-out height** 及以下时，预览变红并禁止放置。调整后保持精确高度，偏移归零也不自动抬升。退出 Paint、更换定义或打开关卡会恢复自动堆叠；旋转和镜像保留偏移。

**Level → Fill ground**：选择带 `ground=true` 的单格定义，设置 Height、Width 和 Depth。矩形从 `X=0, Z=0` 开始，跳过实心格，一次填充可整体撤销。Height 与顶栏共用。

**Level → Transform entire level** 同时旋转或镜像全部位置与朝向，可整体撤销。

## 选择与移动

**Shift+点击**增减选择，Shift 点击空白保持选择。普通点击只选一个实体，点击空白清空选择。手柄位于最后选中的实体上。

- 拖动 XYZ 箭头或 XY/XZ/YZ 方形手柄，按整格移动；整组保持相对位置。只检查终点，可跨越障碍。
- 松开提交一次编辑。非法终点变红，整组恢复原位。**Esc**、隐藏 Grid Levels 或窗口失焦会取消拖动。
- **Duplicate** 沿 +X 复制整组，必要时一起抬升，并选中新副本；失败不创建副本。点击 **Delete**，或在 Select 下按该键，删除整组。

选择不记入撤销历史。撤销删除会恢复实体，但不重新选中。打开关卡或进入形状编辑会清空选择。多选时禁用单实体变换、覆盖和 End 贴地。

### End 向下贴地

Select 下单选实体，按 **End** 将完整形状降到最近实心支撑，保持 X/Z。任一占格获得支撑即可，重力关闭时也可使用。无支撑、起点非法或已经贴地时，不改变位置与历史。

拖动中按 End，即使用 X/Z 手柄也可改变 Y。松开将拖动与贴地合并提交，Esc 整体取消；未拖动时立即生效。

### 高亮与拾取

选中表面蓝色呼吸；Erase 隐藏选择反馈，鼠标指向处红色呼吸；非法移动常亮红色。Select／Erase 拾取可见模型表面，包括占格外的几何，并可穿过受支持的透明区域。Paint 使用逻辑占格表面。详见[自定义材质限制](editor-surface-coverage.zh-CN.md)。

QUACK 白底不透明。编辑器选择用蓝色反馈，运行时选鸭才变黑底。

## 实体定义、属性覆盖与形状

多个实体共享**实体定义**。带加号图标的 **Entity** 新建，**Import…** 导入，**Edit in Inspector** 修改默认值。**Definition options → Save definition as…** 保存为可复用 `.tres`；定义也可内嵌。

[保存](../addons/grid_game_groundwork/editor/level_authoring.gd)也会写入外部定义和规则配置。**Save as…** 保留这些引用，共享修改可能影响其他关卡。默认值修改影响全部继承该值的实体。

只修改一个实体：

1. 选中它，修改 X/Y/Z、**Quarter turns** 或 **Mirrored**。
2. 在 **Property overrides** 添加类型化键值，如浮点数 `weight=4.0`。
3. 点击 **Apply entity changes**，非法终点会被拒绝。

移除键恢复继承。**Reset all overrides** 清空草稿，Apply 提交。复制保留覆盖值与朝向。

| 属性 | 含义 |
| --- | --- |
| `solid`、`movable`、`gravity` | 核心占格、移动、重力行为，可覆盖定义中的对应开关。 |
| `player` | 允许在游戏中选为操作角色。 |
| `can_push`、`pushable` | 默认推动规则下，角色能推动／目标可被推动。 |
| `transmits_push` | 被推动时能否继续推动前方实体；普通和 L 形箱子默认允许连推。 |
| `strength`、`weight` | 使用 `GGStrengthPushRule` 时，角色力量需覆盖全部被推实体的总重量。 |

其他键由玩法规则解释，见[自定义推动](extending.zh-CN.md#自定义推动)。

### 编辑占用格

选择定义，开启 **Edit occupied cells**。**1/2** 在 **Height** 层添加／删除占格，改变 Height 可编辑三维形状。最后一个占格不能删除。**Return to level** 恢复原工具；形状编辑时禁用 Select 和关卡设置。

形状修改影响全部共享实体，支持撤销；用 **Validate** 检查重叠。**Visual Scene** 是独立的 `Node3D` 场景，模型和碰撞体不定义占格。

## 摄像机与快捷键

先让视口获取焦点。**WASD** 沿视角飞行，右键拖动转向，右键+滚轮调速，默认 8、范围 0.25-128 格/秒。**Q/E** 调整 Paint 高度或选中实体；右键+Q/E 始终垂直飞行。非 Paint 且无选择时，Q/E 直接飞行。

飞行和 Shift+中键平移会垂直移动 Height 平面；环绕与缩放保持高度。**Page Up/Down** 单独调整 Height。先结束笔画或拖动再导航；Esc、弹窗、失焦或离开 Grid Levels 会停止导航。

### 操作速查

| 场景 | 输入 | 功能 |
| --- | --- | --- |
| 编辑 | **1 / 2 / 3**，主键盘或小键盘 | 绘制／擦除／选择 |
| 编辑 | 左键点击／拖动 | 使用当前工具 |
| Select | **Shift+点击** | 增减选择 |
| Select 单选／多选 | **Delete** | 删除选中实体 |
| Paint 视口，未绘制 | **Q / E** | 每次按下降低／升高画笔高度偏移一格 |
| Select 视口，单选／多选且未拖动 | **Q / E** | 每次按下降低／抬升选中实体一格 |
| Select | 拖动轴／平面手柄 | 按整格移动选中实体 |
| Select 单选 | **End**，静止或拖动中 | 向下贴到支撑面 |
| 移动中 | **Esc** | 取消整次移动 |
| 编辑 | 右键点击 | 拾取画笔配置 |
| 编辑视口 | **WASD**、**Q/E**（Paint 或选中实体时右键+Q/E） | 沿视角飞行；沿 Y 下降／上升 |
| 编辑视口 | 右键拖动／右键+滚轮 | 转向／调整飞行速度 |
| 编辑工作区 | **Page Up / Page Down** | 放置平面升／降一格 |
| 导航中 | **Esc** | 停止并释放光标 |
| 形状编辑 | **1 / 2**，左键点击／拖动 | 添加／删除占格 |
| 编辑 | **Ctrl/Cmd+S** | 保存 |
| 编辑 | **Ctrl/Cmd+Z** | 撤销 |
| 编辑 | **Ctrl/Cmd+Shift+Z** 或 **Ctrl/Cmd+Y** | 重做 |
| 编辑或游玩 | 中键拖动／**Shift+中键拖动** | 环绕／平移 |
| 编辑或游玩 | 滚轮／**F** | 缩放／完整取景 |
| 游玩 | 空闲时点击玩家实体 | 切换角色 |
| 游玩 | **WASD／方向键** | 固定棋盘方向：W −Z、S +Z、A −X、D +X |
| 游玩 | **Z / Y / R** 或界面按钮 | 撤销／重做／重开 |

工具键、Delete 和 End 需要 Grid Levels 焦点且不按修饰键。文本／属性输入和弹窗保持正常行为。笔画或拖动期间忽略工具切换键，视口快捷键需要视口焦点。

编辑撤销覆盖笔画、实体／整组编辑、形状、填地、设置和变换。Inspector 默认值使用 Godot 的资源编辑与撤销。

## 规则、校验与游玩

在 **Level** 设置标题、**Enable gravity** 和 **Fall-out height**，点击 **Apply level settings**。**Game rule** 选择立即生效，检查其资源可配置推动规则。

地面需显式放置。开启重力时，任一占格下方有支撑即可托住整个刚性实体，悬挑不倾倒。无支撑的堆叠实体一起下落。玩家掉出边界则失败，其他实体从本次尝试移除，均可撤销恢复。

| 规则 | 目标 |
| --- | --- |
| 推箱子 | 每个目标格均被箱子覆盖，且至少有一个目标；可有多余箱子。 |
| 管道 | 全部终点通过互相匹配的端口连到源头，连通管道亮起。 |
| QUACK | 吃掉全部面包。[规则与解法](quack-example.zh-CN.md)。 |
| 无规则 | 测试移动和重力，不提供胜利条件。 |

[Validate](../addons/grid_game_groundwork/data/level.gd) 检查资源结构、ID、形状、实心重叠及掉落边界。保存与试玩运行相同检查，通过不代表谜题有解。

游玩空闲时点击玩家可切换角色，前景占格会遮挡拾取。角色仍存在时，撤销／重做／重开保留选择。摄像机旋转不改变移动方向。快速点按最多缓冲四次移动，长按重复不积压。

**Z** 撤销完整动作，包括推动、下落和机制状态。**Y** 重做，**R** 重开，重开本身也可撤销。胜负后仍能回退。历史操作清空缓冲，等待当前动作结束后执行。自定义进度可连接[完成／失败信号](extending.zh-CN.md#外观与生命周期)。
